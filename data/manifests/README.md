# Manifest Files

These files are safe summary manifests used to describe the public workflow without redistributing patient-level data.

- `clinical_files_summary.csv`: aggregated summary of the clinical source table.
- `pairwise_intersections.csv`: pairwise sample overlap counts across layers.
- `combinations_intersections.csv`: combination-level overlap counts across layers.
- `layer_sample_counts.csv`: aggregate sample counts per layer.
