# Curated Public Results

This directory contains a deliberately small public-facing subset of the original analysis outputs.

- `figures/` includes only figures used in the public narrative and portable presentation.
- `tables/` includes compact summary tables that do not expose patient-level matrices.
- `signatures/` includes final intersection gene lists retained for interpretation.

## Important Note on Factor 3
`signatures/intersection_rna_factor3_genes.txt` is intentionally empty in this public package because the current files do not support a stable RNA overlap for Factor 3. The empty file is retained to document that negative result explicitly rather than hiding it.
